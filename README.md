 🎓 National University (NU) Universal CGPA Calculator

A fast, dynamic, and **100% mobile-friendly** CGPA calculator designed specifically for all departments of National University (NU), Bangladesh. This tool helps students calculate their GPA and CGPA accurately based on credits and letter grades.

🌐 **Live Demo:** [Click Here to Calculate Your CGPA](https://ridwan-akib.github.io/nu-universal-cgpa-calculator/)

---

 ✨ Features
* **Universal Department Support:** Works seamlessly for Honours, Degree, Masters, and Professional courses.
* **Flexible Credits:** Options available for 1, 2, 3, and 4 credit courses.
* **Instant Dynamic Calculation:** Add or delete subjects on the fly.
* **Smart Fail Logic:** Automatically detects and displays if you have failed in any subjects instead of showing a wrong CGPA.
* **Fully Responsive:** Beautiful table layout on desktop that transforms into an optimized view on mobile screens.
* **SEO Optimized:** Structured for fast Google ranking.

---

 🛠️ Technologies Used
* **HTML5:** Structured semantic layout.
* **CSS3:** Custom responsive styling with Flexbox and Media Queries.
* **JavaScript (Vanilla):** Dynamic row generation, real-time input deletion, and CGPA logic evaluation.
